# manufacturing-ontologies

Formal models of manufacturing systems. The primary artifacts are the **Alloy**
behavioral / model-finding models under `alloy/` (run with `make check-alloy`).

`owl/` is a **read-only reference cache** of the public standard ontologies (BFO 2020,
IOF Core, QUDT) we treat as source-of-truth — we no longer maintain an authored OWL
ontology here. See `owl/README.md` and the workbook note `domain-ontology/additional-info.md`.
